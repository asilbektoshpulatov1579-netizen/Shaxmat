3D SHAXMAT - ONLINE SERVER

Fayllar: server.js, package.json, index.html (hammasi bitta papkada bo'lsin)

Kompyuterda sinash:
  npm install
  npm start
  brauzerda http://localhost:3000 oching (ikkita oynada)

Hostingga joylash (masalan Render):
  1. Fayllarni GitHub repository'ga yuklang
  2. Render -> New -> Web Service -> repository'ni tanlang
  3. Build Command: npm install
  4. Start Command: node server.js
  5. Deploy bosing, tayyor havolani do'stingizga yuboring
